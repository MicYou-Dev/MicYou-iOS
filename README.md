</div>

## Features

- **Wi-Fi Connection**: Connect to your PC wirelessly over the local network.
- **Audio Transmission**: Stream audio from your iPhone to your PC in real time.
- **Simple UI**: Clean and intuitive interface for quick setup and use.

## Usage

1. Install the MicYou iOS app on your iPhone.
2. Configure the PC IP address in the app settings.
3. Tap **Connect** to start streaming audio.
